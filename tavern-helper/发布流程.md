# 预设助手版本发布流程

## 版本号规则

- 固定使用 `v0.42.X`，其中 `X` 为递增的非负整数。
- 日常发布只增加 `X`；没有用户明确要求时，禁止修改 `0.42`。
- 构建文件、Git 标签和发布说明使用 `v0.42.X`；当前发布版本：`v0.42.9`。
- `changelog.ts` 中的日志版本与脚本发布版本相互独立。除非用户明确要求新增或修改日志，否则禁止改动
  `CURRENT_CHANGELOG_VERSION` 和 `CHANGELOGS`。

## 发布步骤

1. 确认下一个脚本发布号，只递增 `X`。不要因为发布脚本而自行增加更新日志。
2. 执行预设助手目录的 ESLint 检查：

   ```powershell
   pnpm exec eslint "src/util/酒馆助手脚本/预设助手"
   ```

3. 执行生产构建：

   ```powershell
   pnpm build
   ```

4. 将 `dist/util/酒馆助手脚本/预设助手/index.js` 复制到发布仓库的 `file/index-0.42.X.js`，并同步
   `src/util/酒馆助手脚本/预设助手` 到发布仓库的 `tavern-helper/预设助手`。
   同步共享依赖 `src/util/overlay.ts` 到发布仓库根目录 `overlay.ts`，保留源码中 `../../overlay` 的相对导入关系。
5. 更新发布仓库说明中的版本号与 CDN 链接。不要修改、删除或暂存 `ads_v4.json`。
6. 仅暂存本次版本文件、说明文件和 `tavern-helper` 源码，复核差异后提交：

   ```powershell
   git commit -m "release: preset helper v0.42.X"
   git tag -a "v0.42.X" -m "Preset Helper v0.42.X"
   git push origin main
   git push origin "v0.42.X"
   ```

7. 验证 CDN 文件可以访问：

   ```text
   https://cdn.jsdmirror.com/gh/colerith/riyuexi@v0.42.X/file/index-0.42.X.js
   ```

## 发布前检查

- 总控只识别 ID `098af4e4-5021-4c23-b013-b4646684994b`，名称兜底为 `❖涩涩一键开关❖`。
- 自动判断只读取 `<meow_FM>` 内的 `NSFW：数字/20`。
- 世界书联动在总控开启时必须放行全部条目，在总控关闭时才按配置过滤。
- `ads_v4.json` 保持未修改、未暂存。

## Git 缓存加载版

- 使用 `node scripts/package-preset-git.mjs 0.42.X` 生成主文件、加载器和 SHA-256 发布清单。
- 主文件必须内置 klona，不能带远程模块依赖；对应规则位于模板项目 webpack.config.ts。
- 将主文件与加载器按版本放到 file/，发布清单放到仓库根目录 preset-helper-release.json，与版本标签一起推送。
- 用户应复制加载器完整内容到酒馆助手；缓存更新在下次重载生效。
