# 预设助手版本发布流程

## 版本规则

- 当前发布版本：`v1.0.1`；后续使用 `v1.0.X`，只递增补丁号。
- `changelog.ts` 的用户更新日志独立于脚本发布版本；未明确要求时不要修改。
- 旧 `v0.42.X` 标签、文件及 `preset-helper-release.json` 保留，不覆盖。
- v1 Git 加载器使用 `preset-helper-release-v1.json` 和独立缓存库；旧加载器需替换一次。
- 不修改、删除或暂存 `ads_v4.json`。

## 构建与验证

在模板项目中执行：

```powershell
pnpm exec eslint "src/util/酒馆助手脚本/预设助手" scripts/preset-git-loader/*.ts
pnpm build:preset 1.0.1
node scripts/test-preset-git-loader.cjs
node --experimental-vm-modules scripts/test-preset-local.cjs
```

发布其他补丁号时，将命令中的版本号与本地版测试的产物目录参数同步替换。直接执行 `pnpm build:preset` 默认构建当前版本。

产物位于 `release/preset-helper-v1.0.X-git/`：

- `index-1.0.X.js`：完整主程序，内置 klona，无远程模块依赖。
- `preset-helper-git-loader.js/json`：v1 网络加载版，三源回退、哈希校验、缓存和后台更新。
- `preset-helper-local.js/json`：完整离线压缩版，内置 fflate，运行时解压后执行同一份主程序；不会下载主程序，也不自动更新。
- `preset-helper-release-v1.json`：主程序版本与 SHA-256。
- 许可证文件随对应产物一起发布。

`pnpm build` 仍生成普通主程序；直接粘贴或导入酒馆时优先用压缩本地版 JSON。
悬浮球使用 `icons/` 内的 128px PNG，原尺寸图片保留用于编辑，不再内嵌入主程序。

## 发布

1. 将主程序复制到发布仓库 `file/index-1.0.X.js`。
2. 加载器、本地版及其 JSON 使用带版本号的文件名放入 `file/`，不覆盖旧文件；保留构建产物中的许可证引用文件。
3. 将 v1 清单复制到仓库根目录，保持旧版清单不变。
4. 同步预设助手源码、`icons/`、加载器源码及对应测试；同步共享依赖 `overlay.ts`。
5. 更新 README 的版本与导入说明，验证产物与清单哈希一致。
6. 仅暂存本次相关文件，提交并创建 `v1.0.X` 标签，再原子推送 `main` 和标签。
7. 验证清单和固定标签的主文件可以下载，且 SHA-256 与发布清单一致。

网络版与本地版是同一助手的两种加载方式，只启用其中一种。
