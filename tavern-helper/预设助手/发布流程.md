# 预设助手版本发布流程

## 版本号规则

- 固定使用 `v0.41.X`，其中 `X` 为递增的非负整数。
- 日常发布只增加 `X`；没有用户明确要求时，禁止修改 `0.41`。
- 构建文件、Git 标签和发布说明使用 `v0.41.X`；当前发布版本：`v0.41.6`。
- `changelog.ts` 中的日志版本与脚本发布版本相互独立。除非用户明确要求新增或修改日志，否则禁止改动
  `CURRENT_CHANGELOG_VERSION` 和 `CHANGELOGS`。

## 发布步骤

1. 确认下一个脚本发布号，只递增 `X`。不要因为发布脚本而自行增加更新日志。
2. 执行预设助手目录的 ESLint 检查：

   ```powershell
   pnpm exec eslint "src/util/酒馆助手脚本/预设助手"
   ```

3. 执行生产构建：

   ```powershell
   pnpm build
   ```

4. 将 `dist/util/酒馆助手脚本/预设助手/index.js` 复制到发布仓库的 `file/index-0.41.X.js`，并同步
   `src/util/酒馆助手脚本/预设助手` 到发布仓库的 `tavern-helper/预设助手`。
5. 更新发布仓库说明中的版本号与 CDN 链接。不要修改、删除或暂存 `ads_v4.json`。
6. 仅暂存本次版本文件、说明文件和 `tavern-helper` 源码，复核差异后提交：

   ```powershell
   git commit -m "release: preset helper v0.41.X"
   git tag -a "v0.41.X" -m "Preset Helper v0.41.X"
   git push origin main
   git push origin "v0.41.X"
   ```

7. 验证 CDN 文件可以访问：

   ```text
   https://cdn.jsdelivr.net/gh/colerith/riyuexi@v0.41.X/file/index-0.41.X.js
   ```
